プライバシーポリシー

MovieAutomation(以下「本アプリ」)は、だいふくキーボードが自分の仕事のためだけに使う道具です。

扱う情報

  • Gmail:本人のメール(本文・差出人・件名・ラベル)を読み、本人が確かめた返信を送り、既読にします。
  • YouTube:本人のチャンネルへ動画を上げ、動画の情報を読みます。

使い方と保存

  • 情報は本人のパソコンの中にだけ保存します。
  • 情報を売ったり、広告に使ったり、ほかの人に渡したりしません。

本アプリが Google API から受け取った情報の使い方は、Google API Services User Data Policy(Limited Use の要件を含む)に従います。

English summary

This private tool accesses only the owner's own Gmail and YouTube data. Data is stored only on the owner's computer. Data is never sold, used for ads, or shared with others. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
